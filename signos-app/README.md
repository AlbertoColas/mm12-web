# Nexo

Tu diccionario personal de signos. Graba tus signos, dales un significado y Nexo los reconoce con la
cámara del móvil. Funciona sin conexión y **nunca guarda vídeo**: solo puntos de las manos, en tu teléfono.

> Proyecto en desarrollo. Estado y próximos pasos: [`docs/ESTADO.md`](docs/ESTADO.md).
> El README completo (cómo ejecutarlo, publicarlo e instalarlo en el iPhone) llegará en la Fase 7.

## Arranque rápido
```bash
npm install
npm test
npm run build
```
